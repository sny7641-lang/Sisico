# 사천성 자동 풀이 (Sisen Auto Solver)

「四川省 for Win」 2.13 (Sisen.exe, 小野 晋二 作)을 자동으로 끝까지 풀어 주는 Windows 프로그램입니다.

## 사용법

1. `Sisen.exe`(2.13)를 실행합니다.
2. `SisenAutoSolver.exe`를 실행하고 **[자동 풀기]**를 누릅니다.
3. 프로그램이 판을 읽어 풀이를 계산한 뒤 패를 차례로 클릭합니다. **[중지]**로 언제든 멈출 수 있습니다.

- **클릭 간격(ms)**: 패 한 쌍을 지운 뒤 다음 쌍까지 기다리는 시간입니다. 0으로 두면 가장 빠릅니다.
- **풀 수 없는 배치면 자동으로 새 게임**: 이 게임은 패를 완전히 무작위로 섞기 때문에 약 5%의 판은 원래부터 끝까지 풀 수 없습니다. 이 옵션을 켜 두면 그런 판에서 새 게임(F2)을 시작해 다시 풉니다. 끄면 가능한 만큼만 지웁니다.
- 실제 마우스 커서를 움직이지 않고 게임 창에 클릭 메시지를 보내므로, 게임 창이 다른 창에 가려져 있어도 동작합니다(최소화된 상태는 제외).

## 랭킹과 * 표시

게임은 「검색(F8)」이나 「되돌리기(F9)」를 쓴 판의 경과 시간 앞에 `*`를 붙이고, 그 판은 랭킹에 기록하지 않습니다.

- **기본값(체크 해제)**: 이 프로그램은 F8/F9를 쓰지 않으므로 `*`가 붙지 않습니다. 대신 자동으로 푼 기록이 로컬 랭크 파일에 일반 기록처럼 남습니다.
  게임 Readme는 도구로 얻은 기록을 **월드 랭킹(인터넷)에 등록하는 것을 금지**하고 있으니 등록하지 마세요.
- **「경과 시간에 * 표시」 체크**: F8을 쓴 판과 같은 표시를 켭니다. `*`가 붙고 랭킹에 기록되지 않습니다.

이 표시는 새 게임을 시작하면 게임이 스스로 지웁니다. 이 프로그램은 표시를 지우지 않으므로, 같은 판에서 직접 F8/F9를 썼다면 `*`는 그대로 남습니다.

## 동작 원리

Sisen.exe 2.13을 정적으로 분석해 알아낸 구조를 사용합니다. 이미지 베이스는 0x400000이고 재배치 정보가 없어서 주소가 고정입니다.

| 항목 | 위치 |
|---|---|
| 메인 창 객체 vtable | `0x004339A8` (`+0x1C`가 창 핸들) |
| 보드 | 객체 `+0xF8`, `int[8][18]`, 패 번호 또는 -1 |
| 패 종류 | 객체 `+0x7B8`, `BYTE[144]` (패 번호 → 종류) |
| 도움 표시(`*`) | 객체 `+0x1274` (검색/되돌리기 사용 시 1, 새 게임에서 0) |
| 클릭 상태 | 객체 `+0x12B8` (1 대기, 2 한 장 선택, 3 제거 중), 선택 위치 `+0x128C`/`+0x1290` |
| 보드 원점 / 칸 크기 | `0x0043F0D8`, `0x0043F0DC` / `0x0043F104`, `0x0043F108` |

1. 최상위 창들 중에서 위 코드 서명이 일치하는 프로세스를 찾고, 메모리에서 vtable과 창 핸들이 맞는 객체를 찾습니다.
2. 보드를 읽고 깊이 우선 탐색(방문한 상태는 기억해 다시 탐색하지 않음)으로 전체 풀이를 찾습니다.
   제거 규칙은 게임의 판정 함수(`0x403DC0`)와 같습니다: 같은 종류의 두 패를 빈 칸만 지나는 최대 두 번 꺾인 선으로 이을 수 있으면 제거할 수 있고, 선은 판 바깥 한 칸을 지나가도 됩니다.
3. 풀이를 `WM_LBUTTONDOWN/UP` 메시지로 실행하고, 매 수마다 게임 메모리를 다시 읽어 결과를 확인합니다. 도중에 사용자가 직접 클릭해 판이 바뀌면 다시 계산합니다.

다른 버전(예: 2.03)은 주소가 달라 인식하지 않습니다.

## 빌드

Linux에서 크로스 컴파일:

```sh
sudo apt-get install gcc-mingw-w64-i686
make            # SisenAutoSolver.exe
make test       # 풀이 엔진 테스트 (호스트 컴파일러 사용)
```

Windows(MSYS2 MinGW 32-bit)에서는 `make CC=gcc`.

`make test`는 경로 판정을 별도 BFS 구현과 130만 쌍 이상 비교하고, 무작위 배치 200판을 풀어 결과 수순을 다시 검증합니다.
